A one-line office joke entered in make.fun's "One-Line Office Joke: 24-Hour Sprint". The program writes a single joke about office life — the colleague whose every "quick question" is neither quick nor a question — to `/output/entry.txt`, where an AI judge compares it head-to-head against the other entries in blind rounds.

## The joke

> My coworker opens every interruption with 'quick question' — three years in, not one has been quick, and several weren't even questions.

## Run it

```sh
python3 main.py
```

The program checks the line is a single line of 1 to 200 characters and writes it to `/output/entry.txt`. It prints nothing: the graded artifact is the file alone.
